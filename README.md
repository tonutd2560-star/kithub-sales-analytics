## 📈 ฟีเจอร์หลักของระบบ:
1. **Key Performance Indicators (KPIs):**
   - ยอดขายรวมสุทธิ: ฿10,208,323
   - จำนวนคำสั่งซื้อที่สำเร็จ: 9,245 รายการ
   - ยอดเฉลี่ยต่อออเดอร์ (AOV): ฿1,104
   - จำนวนชิ้นสินค้าที่ขายได้: 17,160 ชิ้น
   - คะแนนรีวิวเฉลี่ย: 4.28 / 5.0
2. **กราฟวิเคราะห์ข้อมูล (Interactive Charts):**
   - ยอดขายตามหมวดหมู่สินค้า (อิเล็กทรอนิกส์, แฟชั่น, บ้านและสวน, ฯลฯ)
   - ยอดขายตามภูมิภาค (ภาคกลาง, ภาคเหนือ, ภาคอีสาน, ภาคตะวันออก, ภาคใต้)
   - ยอดขายตามช่องทางการจำหน่าย (แอปมือถือ, เว็บไซต์, หน้าร้าน, โซเชียลมีเดีย)
   - สัดส่วนวิธีการชำระเงิน (พร้อมเพย์, บัตรเครดิต, เก็บเงินปลายทาง, ฯลฯ)
   - 10 อันดับสินค้าที่ทำยอดขายสูงสุด (Top 10 Revenue Products)
3. **ตารางสำรวจข้อมูล (Data Explorer Table):**
   - ค้นหาข้อมูลแบบเรียลไทม์ (Search by Order ID, Product, Province)
   - กรองข้อมูลตามหมวดหมู่, ภูมิภาค, ช่องทาง, วิธีชำระเงิน
   - ระบบแบ่งหน้า (Pagination) 25 แถวต่อหน้า
4. **สรุปรายงานการคลีนข้อมูล (Data Cleansing Summary):**
   - ข้อมูลตั้งต้น: 10,000 แถว
   - คัดกรองข้อมูลขยะออก 755 แถว (คำสั่งซื้อยกเลิก 471 แถว, สินค้าคืน 284 แถว)
   - คงเหลือข้อมูลคุณภาพสูง: 9,245 แถว (92.45%)
